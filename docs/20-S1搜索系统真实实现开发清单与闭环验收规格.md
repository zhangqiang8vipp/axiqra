## 1. 文档定位

本文是 S1 四主链中的第一条专项文档：搜索系统真实实现。

搜索系统不是一个输入框，也不是简单关键词查询。Axiqra 的搜索承担 Search Before Act 的核心责任：AI 工具和人类用户在行动前，必须先看到已经被授权、脱敏、审核、验证并且适配当前工程上下文的工程方案记忆。

因此，S1 搜索必须做到：

1. 未登录只能看公开、脱敏、允许展示的内容。
2. 登录 Web 搜索按用户基础入口、所属空间、授权范围和高级能力累加后，再做 ABAC 裁剪。
3. MCP `axiqra.search_before_act` 必须受 token scope、ABAC 和每日 10 次默认 quota 同时约束。
4. 搜索必须先权限预过滤，再召回，再排序，再解释，再展示。
5. 搜索结果必须可审计、可复验、可回归。
6. 发布、撤回、污染隔离、审核状态变化必须影响索引和召回。

## 4. 搜索访问通道

搜索必须按访问通道分开设计。不能把未登录 Web、登录 Web 和 MCP 工具调用混成一套权限。

| 通道 | 主体 | 入口 | 召回范围 | quota | 必须拒绝 |
|---|---|---|---|---|---|
| 未登录 Web 搜索 | anonymous visitor | 公开搜索页 / 公开传播页 | Public Space 中已公开、已脱敏、允许展示的 Solution / Public Case / Candidate Seed 摘要 | 公开风控限流，非 MCP quota | 私有 Trace、Project Case、团队、小组、企业、导出、MCP |
| 登录 Web 搜索 | authenticated user | 登录后搜索框、个人空间、团队 / 企业上下文 | 公开 + 本人 + 所属空间 + 授权范围 + 高级能力可见内容 | 产品套餐或 Web 策略另行定义 | 未授权空间、未授权对象、被隔离内容 |
| 登录 MCP 搜索 | authenticated user + MCP token | `axiqra.search_before_act` | token scope 内，且用户本身可见内容 | 普通登录用户 S1 默认每日 10 次 | 无 token、scope 缺失、quota 超额、ABAC 拒绝 |
| 审核后台搜索 | reviewer / official reviewer | 审核队列内部搜索 | 授权审核范围内内容，必要时只看脱敏摘要 | 不等于 MCP quota | 未分配租户、未授权私有对象、官方身份越权 |
| 运维 / 安全排障搜索 | platform ops / security | 后台排障入口 | 最小必要权限和强审计下的对象 | 独立运维策略 | 无工单、无审批、无审计、跨租户泛查 |

## 5. 累加式权限要求

搜索系统必须继承 D03、D13 和 D19 的累加式权限模型。

```text
search_visible_set =
  public_visible_set
  + user_owned_set
  + membership_visible_set
  + granted_scope_visible_set
  + governance_visible_set
  + admin_visible_set
  -> ABAC filter
  -> channel filter
  -> quota / risk filter
```

| 主体 | 基础搜索入口 | 空间搜索入口 | 高级搜索入口 | MCP 默认 10 次是否保留 | 不允许的实现 |
|---|---|---|---|---|---|
| 普通登录用户 | 保留 | 按成员关系 | 无 | 是 | 把 Web 权限扩大到 MCP token 外 |
| 团队成员 | 保留 | 团队 / 项目 / 小组 | 无 | 是 | 登录团队后丢失个人入口 |
| 企业成员 | 保留 | 企业 / 租户 | 无 | 是 | 企业内容参与公共召回 |
| 审核者 | 保留 | 按成员关系 | 审核授权范围 | 是 | 审核者默认可搜全站私有内容 |
| Maintainer | 保留 | 按成员关系 | 维护授权范围 | 是 | Maintainer 绕过 quota |
| 企业管理员 | 保留 | 企业管理范围 | 企业治理入口 | 是 | 管理员身份替换普通用户导航 |
| 官方审核人员 | 保留 | 按授权范围 | 官方审核入口 | 是 | 官方身份匿名覆盖普通审核 |

### 7.1 Web 搜索 API

| 项 | 规格 |
|---|---|
| 路径 | `GET /api/search` 或 `POST /api/search/query` |
| 适用主体 | 未登录 Web、登录 Web |

| 未登录限制 | `channel = public_web`，只允许 public 可见结果 |
| 登录限制 | 登录态 + membership + grants + ABAC |
| 错误 | `ABAC_DENIED`、`QUERY_INVALID`、`RATE_LIMITED`、`CONTENT_QUARANTINED` |

### 7.2 MCP 搜索工具

| 项 | 规格 |
|---|---|
| 工具名 | `axiqra.search_before_act` |
| 适用主体 | 登录用户 + MCP token |
| 必填输入 | `task_goal`、`context`、`request_id` |
| 条件输入 | `workspace_id`、`risk_hint`、`expected_action`、`prior_attempts` |
| 输出 | `ranked_results`、`risk_hints`、`required_confirmation`、`quota_limit`、`quota_used`、`quota_remaining` |
| quota | 普通登录用户 S1 默认每日 10 次 |
| scope | 必须包含 `search:read` |
| 错误 | `LOGIN_REQUIRED`、`SCOPE_DENIED`、`QUOTA_LIMITED`、`ABAC_DENIED` |

### 7.3 审核后台搜索 API

| 项 | 规格 |
|---|---|
| 路径 | `GET /api/review/search` |
| 适用主体 | reviewer / official reviewer |
| 必填输入 | `query`、`queue`、`request_id` |
| 输出 | `review_items`、`risk_summary`、`decision_filters`、`audit_id` |

## 10. 多路召回规格

| 召回路 | 输入 | 输出 | 必须过滤 | 说明 |
|---|---|---|---|---|
| exact_error_recall | error_signature | 精确错误命中 | 权限、状态、脱敏 | 高优先级但不可越权 |
| keyword_recall | query_text、title、tags | 关键词候选 | 权限、状态 | S1 基础召回 |
| structured_recall | tech_stack、version、risk | 结构化候选 | 权限、状态 | 精确筛选 |
| vector_recall | query embedding | 语义候选 | 权限、状态 | S1 可轻量，保留迁移 |
| failure_path_recall | prior_attempts、failed feedback | 失败路径候选 | 权限、状态 | 避免重复错误 |
| space_recall | current_space | 空间候选 | membership、ABAC | 项目/团队/企业优先 |
| seed_recall | gap / empty result | Candidate Seed | public / authorization | 空结果补缺口 |

召回合并要求：

1. 合并后按对象 ID 去重。
2. 每个结果保留命中召回路。
3. 命中原因进入 `fit_reason`。
4. 任一召回路不得绕过权限预过滤。

## 11. 排序公式 v1

S1 不追求复杂模型，但必须可解释、可调、可回归。

```text
rank_score =
  context_fit_score
  + exact_error_boost
  + tech_stack_score
  + verification_score
  + evidence_score
  + space_priority_score
  + recency_score
  + feedback_score
  - risk_penalty
  - not_applicable_penalty
  - stale_penalty
```

| 特征 | 来源 | 方向 | 解释要求 |
|---|---|---|---|
| context_fit_score | 查询理解 | 越高越靠前 | 说明匹配的上下文 |
| exact_error_boost | 错误签名 | 精确命中加权 | 展示命中错误 |
| tech_stack_score | 技术栈字段 | 精确匹配加权 | 展示版本适配 |
| verification_score | L0-L5 | L 越高越靠前 | 展示验证等级 |
| evidence_score | Evidence | 证据越强越靠前 | 展示证据摘要 |
| space_priority_score | 空间距离 | 当前项目优先 | 展示来源空间 |
| recency_score | 最近验证 | 新近加权 | 展示时间 |
| feedback_score | worked / failed | worked 提升，failed 降低 | 展示反馈摘要 |
| risk_penalty | R0-R4 | 风险越高越谨慎 | 展示风险提示 |
| not_applicable_penalty | 不适用反馈 | 降权 | 展示不适用原因 |
| stale_penalty | 过期规则 | 降权 | 展示过期提示 |

## 13. 错误码

| 错误码 | HTTP | 场景 | 是否消耗 quota | 是否召回 | 必须字段 |
|---|---:|---|---|---|---|
| QUERY_INVALID | 400 | 空查询、超长、非法结构 | 否 | 否 | request_id、repair_hint |
| LOGIN_REQUIRED | 401 | 未登录调用 MCP | 否 | 否 | request_id、tool |
| SCOPE_DENIED | 403 | token 缺 `search:read` | 否 | 否 | required_scope、current_scope |
| ABAC_DENIED | 403 | 当前主体无对象或空间权限 | 视通道 | 否 | policy_code、object_type |
| QUOTA_LIMITED | 429 | MCP 第 11 次 | 是，已达上限 | 否 | quota_limit、quota_used、quota_remaining |
| RATE_LIMITED | 429 | 公开 Web 风控限流 | 否 | 否 | retry_after |
| CONTENT_QUARANTINED | 423 | 结果或索引处于隔离 | 否 | 否 | quarantine_reason |
| INDEX_UNAVAILABLE | 503 | 索引不可用 | 否 | 否或安全降级 | fallback_mode |

错误响应必须结构化，不能只返回文本。MCP quota 超额必须明确 `quota_remaining = 0`。
