# v2.0 样例证据目录

本目录是 v2.0 的最小样例证据包，用于把 v1.9 的路径级映射推进到“有样例文件可核验”的状态。

当前样例覆盖：

| 目录 | 作用 | 闭环状态 |
|---|---|---|
| `mcp/` | MCP `search_before_act` 第 1 / 10 / 11 次、scope 拒绝响应样例 | 样例层是；真实服务响应待接入 |
| `anonymous/` | 未登录公开搜索和私有隔离响应样例 | 样例层是；真实页面截图和 API 待接入 |
| `audit/` | MCP quota 审计事件样例 | 样例层是；真实审计日志待接入 |
| `reports/` | CI 报告样例 | 样例层是；真实 CI 运行结果待接入 |

固定原则：

1. 未登录用户只能做公开 Web 搜索，不能调用 MCP，不能看到私有标题、空间、Trace 或 Project Case。
2. 普通登录用户 MCP 搜索默认每日 10 次，第 11 次必须返回 `429 / QUOTA_LIMITED`，并且 `no_recall_performed = true`。
3. 企业管理员、审核者、Maintainer 等高级身份只叠加能力，不自动绕过普通入口、ABAC 或默认 quota。
